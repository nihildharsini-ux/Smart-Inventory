Smart Inventory App

A web-based application for managing shop inventory, billing, and sales.

Features
- User Registration and Login
- Product Management
- Stock Updates and Low-Stock Alerts
- Billing and Automatic Stock Reduction
- Sales History and Dashboard
- Shop Settings

Technologies Used
HTML, CSS, JavaScript, Local Storage

 How to Run
1. Download the repository.
2. Open `Smart Inventory.html` in a web browser.
3. Register and start using the application.

 Project Type
College Mini Project
